# Security policy

## Supported versions

Security fixes are applied to the latest `v1` release. Consumers with strict supply-chain requirements should pin a full commit SHA and use Dependabot to review updates.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or include an API token, response payload, customer identifier, or request body in an issue.

Use GitHub's **Security → Report a vulnerability** private reporting flow for this repository. Include the affected version, impact, reproduction steps with synthetic data, and any suggested remediation. Pangolinfo will acknowledge a valid report as soon as practical and coordinate disclosure after a fix is available.

If private vulnerability reporting is unavailable, contact Pangolinfo through the support channel listed at <https://www.pangolinfo.com/contact-us/> and request a secure reporting path.
